# Библейские истории · boris (`biblejskie-istorii-boris`)

Гибрид: **неизменённое ядро** из [boriscards](../boriscards) + том «Библейские истории»
(контент и оболочка из `biblejskie-istorii`, без форка движков в `core/`).

## Запуск

Открой в браузере:

- `index.html` → редирект в колоду
- или сразу `decks/biblejskie-istorii/index.html`

Разделы: **В путь** (лента эпох) · Карты · Книги · Стройка · Игры · Словарик · Родителям.

## Архитектура (правила платформы)

| Слой | Где | Правило |
|------|-----|---------|
| Ядро | `core/` | Копия `boriscards/core` **без правок**. Движки только здесь. |
| Колода | `decks/biblejskie-istorii/` | Контент, оболочка, плагины `FEED_KINDS`, песочницы игр |
| Лента | `core/engines/feed` + `feed/kinds-colors.js` | Главы тома; «цвета радуги» — плагин колоды |
| Книги | `core/engines/encyclopedia` | 6 ридеров в `books/` + томная книга `book/` |
| Хаб | `decks/.../quest/` | Копия quest из исходного тома **только в колоде** (ядро не трогаем) |
| Игры | `games/jigsaw-sandbox.js` | Пазл-история вне ядра |

## Что сохранено

40 карт (герои + сюжеты), лента ~389 экранов, 6 аудиокниг, стройки, словарик,
игры хаба (в т.ч. ковчег-flappy), 7 языков оболочки, раздел «Родителям».

## Версии ядра

`core/` синхронизируйте копированием из `boriscards/core` (не править файлы
внутри `biblejskie-istorii-boris/core/`).
