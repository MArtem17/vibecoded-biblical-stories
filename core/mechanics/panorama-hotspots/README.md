# Панорама с хотспотами (`panorama-hotspots`)

Переиспользуемый режим **«панорама + кликабельные точки»** для любой колоды: большое
изображение (пан/зум) или картинка «в размер экрана», на ней точки-хотспоты, тап по точке
открывает карточку (картинка + заголовок + текст). Опционально — видео-заставка при открытии
и звук на хотспот.

Извлечён из колоды «Большой театр» (`decks/kulturnyy-pasport`), где на схеме театра так сделаны
разборы: плафон, оркестр (со звуком), зал, закулисье, фасад-квадрига, пожар; занавес — с видео.

- **Без зависимостей.** ES5, vanilla, один файл, CSS вставляет сам. Офлайн, iOS WKWebView.
- **Ничего не ломает.** Строит свой оверлей поверх страницы, зовётся по API.

## Подключение

```html
<script src="core/mechanics/panorama-hotspots/panorama-hotspots.js"></script>
<script>
  PanoramaHotspots.open({
    image: 'assets/hall.webp',            // обязательно: картинка сцены
    hint:  'Нажми точку — узнай, что это',
    pan:   true,                          // true = панорама (пан/зум); false = вписать в экран. По умолч. true
    base:  'assets/hall/',                // опц.: префикс для hotspot.image и hotspot.audio
    intro: 'assets/hall/intro.mp4',       // опц.: видео-заставка (проиграется 1 раз → замрёт в панораму)
    hotspots: [
      { x:50, y:20, title:'Аполлон', subtitle:'бог искусств',
        text:'…', image:'apollo.webp', audio:'apollo.mp3' }
    ]
  });
</script>
```

Открой `demo/index.html` — рабочий пример (пан/зум и «в размер экрана»).

## Конфиг сцены

| поле | тип | назначение |
|------|-----|-----------|
| `image` | string | **обязательно.** URL картинки сцены/панорамы |
| `pan` | bool | `true` (по умолч.) — пан/зум панорамы; `false` — вписать в экран |
| `hint` | string | подсказка-пилюля сверху (нет — не показывается) |
| `intro` | string | URL видео-заставки (mp4, muted+playsinline); играет 1 раз при открытии |
| `base` | string | префикс, добавляется к `hotspot.image` и `hotspot.audio` |
| `okLabel` | string | текст кнопки закрытия карточки (по умолч. «Понятно») |
| `onOpenCard` | function(h, idx) | колбэк при открытии карточки хотспота |
| `hotspots` | array | список точек (см. ниже) |

### Хотспот

| поле | тип | назначение |
|------|-----|-----------|
| `x`, `y` | number | координаты центра точки в **процентах** от изображения (0–100) |
| `title` | string | заголовок карточки |
| `subtitle` | string | подзаголовок/роль (капитель) |
| `text` | string | текст-факт |
| `image` | string | картинка-герой карточки (крупный план); нет — монограмма из первой буквы |
| `audio` | string | mp3 → в карточке появляется кнопка ▶ |
| `audioLabel` | string | подпись кнопки звука (по умолч. «Послушать») |

## API

```js
PanoramaHotspots.open(scene);            // открыть сцену-объект
PanoramaHotspots.register('hall', scene);// зарегистрировать по id …
PanoramaHotspots.open('hall');           // … и открыть по id
PanoramaHotspots.edit(scene);            // редактор разметки (см. ниже)
PanoramaHotspots.close();                // закрыть
```

## Редактор хотспотов (ручная установка точек)

Встроен в модуль — отдельная страница не нужна:

```js
PanoramaHotspots.edit(scene);   // та же сцена, но в режиме разметки
```

- **тап по картинке** — ставит новую точку (синий маркер с номером);
- **потащи маркер** — подвинешь точку;
- снизу — панель с готовым `hotspots:[{x:..,y:..},…]` (координаты в % от изображения):
  **⧉ Скопировать JSON** (кладёт в буфер и в console.log), **↩ Удалить последнюю**, **✕ Закрыть**;
- если у сцены уже есть `hotspots` — они подхватываются в редактор (можно поправить
  существующую разметку); остальные поля точек (`title`, `image`, …) сохраняются в выводе;
- пан/зум в редакторе работают: короткий тап — точка, длинное движение — панорамирование.

Скопированный блок вставляешь в конфиг сцены и дописываешь тексты/картинки.

Альтернатива без рук (как делали в «Большом»): наложить сетку 10% на изображение скриптом,
прочитать центры объектов, проверить кружками-оверлеем. Тап-зона крупная (36px), небольшие
неточности прощаются.

