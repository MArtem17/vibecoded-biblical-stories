# Globe — переиспользуемый вращающийся глобус

Самодостаточный компонент «крутящийся глобус» на `<canvas>`. **Vanilla ES5, без
зависимостей и шага сборки**, работает офлайн в WKWebView (iOS). Предназначен для
переиспользования в любых продуктах платформы — подключил `globe.js`, дал
`<canvas>` и текстуру, вызвал `Globe.create(...)`.

Выделен из движка географии (`decks/geografiya-5-6/sim/index.html`, симуляция
«Вращение Земли» — функции `initEarthDayNightSim` / `renderGlobe`). Здесь —
чистое ядро без привязки к конкретной колоде (без Солнца/неба/маркера Москвы).

## Демо

```bash
cd core/components/globe
python3 -m http.server 8000
# открыть http://localhost:8000/    (index.html)
```

Живьём: авто-вращение, перетаскивание пальцем/мышью, переключение режимов
освещения и скорости.

## Как встроить

```html
<canvas id="g" width="320" height="320"></canvas>
<script src="globe.js"></script>
<script>
  var globe = Globe.create({
    canvas: 'g',                // id или сам элемент <canvas>
    texture: 'world_tex.jpg',   // equirectangular карта мира (соотношение 2:1)
    autoRotate: true,
    speed: 0.35,                // рад/сек
    drag: true,
    light: 'sphere'             // 'sphere' | 'daynight' | 'flat'
  });
</script>
```

Канвас считается квадратным; глобус вписывается в него и учитывает Retina
(`devicePixelRatio`, по умолчанию капается на 2).

## Опции `Globe.create(opts)`

| Опция | По умолчанию | Что делает |
|-------|--------------|------------|
| `canvas` | — (обяз.) | id строкой или элемент `<canvas>` |
| `texture` | `'world_tex.jpg'` | URL equirectangular-текстуры 2:1 (same-origin) |
| `autoRotate` | `true` | авто-вращение при старте |
| `speed` | `0.35` | скорость вращения, рад/сек |
| `drag` | `true` | вращение перетаскиванием (мышь + touch) |
| `light` | `'sphere'` | освещение: `sphere` (объём), `daynight` (терминатор день/ночь), `flat` (без затенения) |
| `sun` | `{x:-0.8,y:0,z:0.6}` | направление на Солнце (экранные координаты) для `daynight` |
| `pixelRatio` | `2` | потолок DPR для резкости/производительности |
| `maxFPS` | `40` | троттлинг кадров |
| `lon`, `lat` | `0`, `0` | стартовые углы: долгота (yaw) и наклон вида (pitch), рад |
| `background` | `'transparent'` | заливка канваса под глобусом |

## API экземпляра

| Метод | Действие |
|-------|----------|
| `start()` / `stop()` | запустить / остановить анимацию |
| `setSpeed(radPerSec)` | сменить скорость |
| `setLight(mode)` | сменить режим освещения на лету |
| `rotateTo(lonRad, latRad)` | выставить углы |
| `resize()` | перечитать размер канваса (после смены размера контейнера) |
| `destroy()` | снять обработчики и очистить канвас |
| `.running` | флаг: идёт ли анимация |

## Текстура

`world_tex.jpg` — равнопромежуточная (equirectangular) карта мира **2:1**
(1024×512, ~71 КБ). Можно подменить на любую свою карту того же формата
(политическую, ночную, Марс и т.п.) — важно лишь соотношение 2:1 и проекция
plate carrée.

## Ограничения

- Текстура читается пиксельно (`getImageData`), поэтому источник должен быть
  **same-origin** (или отдаваться с CORS), а страница — открыта по `http(s)`, не
  `file://`. Иначе canvas «протухает» и глобус рисуется заглушкой-сеткой (это
  штатный фолбэк, не ошибка).
- Рендер софтверный (пер-пиксельный цикл в JS). Для крупных глобусов на слабых
  устройствах уменьшайте размер канваса или `pixelRatio`/`maxFPS`.
