# core/kit — движок энциклопедии-игры

Переиспользуемое ядро: один движок оживляет любой предметный набор (страны, тело
человека, космос, динозавры…). Колода-инстанс приносит **только данные**, движок
строит весь UI сам.

```
core/kit/
  kit.css   дизайн-система (высокий контраст, «нажми», iOS-safe)
  kit.js    движок: главный экран, уроки, игра «Что это?», звёзды,
            уровни, родительский режим (замок+статистика+настройки)
  README.md этот файл
```

## Как собрать новую энциклопедию за 3 файла

```
decks/<slug>/
  index.html   — 10 строк: подключает kit.css, config.js, content.js, kit.js
  config.js    — window.KIT_CONFIG (паспорт: id, темы, уровни, тексты)
  content.js   — window.KIT_CONTENT = { items:[…] } (предметы + факты)
```

`index.html` — ровно этот шаблон (пути к ядру относительные):

```html
<!doctype html><html lang="ru"><head>
<meta charset="utf-8">
<meta name="viewport" content="width=device-width,initial-scale=1,maximum-scale=1,user-scalable=no,viewport-fit=cover">
<title>…название… · Образовариум</title>
<link rel="stylesheet" href="../../core/kit/kit.css">
</head><body>
<div id="app"></div>
<script src="config.js"></script>
<script src="content.js"></script>
<script src="../../core/kit/kit.js"></script>
</body></html>
```

Эталон-инстанс — [`decks/telo-cheloveka/`](../../decks/telo-cheloveka/)
(«Тело человека»: 7 систем, 20 органов). Полный контракт полей и что делает
движок — [`docs/product-kit.md`](../../docs/product-kit.md).

## Что умеет движок (из коробки, без кода)

- **Главный экран:** маскот, прогресс «освоено N из M», плитки-темы с
  прогресс-барами, кнопка игры «Что это?».
- **Урок («В путь!»/тема):** карточка знакомства (эмодзи+название+факт) →
  вопросы по навыкам (`round`) → звёзды → «переменка» с детским фактом → дневник.
- **Игра «Что это?»:** 10 вопросов в режимах `quiz` (название / тема /
  узнавание), варианты с подсветкой верного.
- **Звёзды:** пожизненный счётчик, летящая ⭐ к бейджу за каждый верный ответ.
- **Уровни:** лестница рангов из `config.ranks`, порог — % освоенных предметов.
- **Родительский режим:** замок-пример (умножение) → прогресс по темам,
  статистика ответов по навыкам, настройки (голос, число вариантов), сброс.

## localStorage

Все ключи с неймспейсом `config.id` — колоды **не пересекаются**:
`<id>_prog_v1`, `<id>_earned`, `<id>_log_v1`, `<id>_optn`, `<id>_voice`.
