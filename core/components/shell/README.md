# core/components/shell — общая оболочка колод-энциклопедий

Нижняя навигация из четырёх режимов, звёзды за верные ответы с прилётом к
счётчику, звания и родительский раздел за воротами-примером. Раскладка
отлажена на «Кругосветке» (`decks/strany-mira`); здесь она вынесена в `core/`,
чтобы перестать копироваться.

```
shell/
  shell.js    ← навигация, звёзды, звания, родительский лист
  shell.css   ← вид; цвета берутся из переменных страницы
  README.md
```

## Зачем вынесли

Копий было две: «Кругосветка» и «Мировое искусство» (последнее взяло оболочку
копией — см. его `deck.json`, «на ядре оболочки Кругосветки»). Они уже
расходились. Третья копия во «Словаре на сценах» окончательно развела бы
родительский отчёт по трём разным реализациям, а правило платформы — «логика
живёт только в `core/`» (CLAUDE.md §2).

**«Кругосветка» и «Искусство» пока НЕ переведены** и работают на своих копиях.
Это осознанно: перенос трёх колод одним махом — ровно то, что §8 CLAUDE.md
запрещает («не переписывать движки в один одним махом»). Их переносим
отдельной задачей, когда оболочка обкатается на словаре.

## Подключение

```html
<link rel="stylesheet" href="../../../core/components/shell/shell.css">
<script src="../../../core/components/shell/shell.js"></script>
```

```js
Shell.mount({
  starKey: 'sns_stars_en',       // где копятся звёзды (см. ниже — ключ может быть не один)
  badge: 'stars',                // id элемента-счётчика в шапке
  ranks: [{at:0,name:'Слушатель'}, {at:50,name:'Читатель'}, …],
  active: 'cards',
  tabs: [
    {id:'cards',  icon:'🂠', label:'Карточки'},                 // без href — свой экран
    {id:'games',  icon:'🎯', label:'Упражнения', href:'…'},     // с href — переход
    {id:'dict',   icon:'📖', label:'Словарь',    href:'…'},
    {id:'parent', icon:'👪', label:'Родителям'}                 // особый id: открывает лист
  ],
  renderParent: function (box, info) { box.innerHTML = …; }     // статистику пишет КОЛОДА
});
```

## Наружу

```js
Shell.earn(n, srcEl)   // начислить n звёзд; srcEl — откуда полетит звезда
Shell.stars()          // сколько накоплено
Shell.rankOf(n)        // {name, next, need} — звание и сколько до следующего
Shell.setStarKey(key)  // сменить копилку на ходу
Shell.openParent()     // открыть родительский лист
```

## Что важно знать

- **Ключ звёзд — параметр, а не константа.** Во «Словаре на сценах» шесть
  языков изучения на одном контенте, и прогресс уже хранится по паре «язык +
  слово». Общая копилка врала бы: выученное `kitchen` не делает выученным
  `die Küche`. Поэтому при смене языка колода зовёт `setStarKey()`.
- **Прилёт звезды — не украшение.** Это единственное место, где ребёнку видно,
  что ответ засчитан: счётчик в углу сам по себе меняется незаметно.
- **Ворота родительского раздела — не защита, а порог**, который ребёнок не
  перешагнёт случайно. Пример на умножение, как в «Кругосветке».
- **Оболочка не знает про контент.** Ни про слова, ни про страны: что показать
  в отчёте, решает колода в `renderParent`.
- **Навигация `position:fixed`** — странице нужен нижний отступ под неё, иначе
  она ляжет поверх собственных кнопок экрана.

Проверка подключения — `tools/node/check_slovar_cards.js`: навигация
смонтирована, звезда начисляется за ответ, у другого языка своя копилка,
родительский раздел закрыт воротами и открывается верным ответом.

## Только звёзды, без нижней панели

`mount()` без `tabs` не строит нижнюю навигацию вовсе. Это нужно страницам, у
которых своя навигация, а от оболочки требуется одна вещь — счётчик звёзд с
прилётом: так «Словарь» колоды `slovar-na-stsenah` берёт ту же копилку, что и
его же «Карточки», не получая второй ряд кнопок внизу.

    Shell.mount({ starKey: 'sns_stars_en', badge: 'stars', ranks: RANKS });

Копилку можно переключать на ходу (`setStarKey`) — у этой колоды звёзды свои у
каждого языка изучения.
