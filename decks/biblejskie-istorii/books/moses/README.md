# Конвейер озвученных книг (мультиязычные)

Производит озвученную книгу-ридер сразу на нескольких языках из одной точки
входа — `book.json`. Пример собран на «Истории Моисея» (16 страниц).

## Главный принцип

**Текст не впечатан в картинку — он накладывается ридером сверху.** Поэтому:

- **Иллюстрации — общие для всех языков, генерим один раз.** 16 картинок — это
  16 файлов, а не 16×N.
- На язык форкаются только **текст** и **озвучка**.
- Верхняя зона каждой картинки держится пустой под текст — под **самый длинный
  язык** (немецкий/русский длиннее английского). Это правило зашито в промпт.

## Консистентность персонажа

Один раз генерим эталон персонажа (`_anchor.png`), дальше каждая страница —
это `images.edit` от эталона + блок «что сохранить». Персонаж не плывёт между
страницами. На страницах без персонажа эталон подаётся только как референс стиля.

## Что под капотом (по гайду gpt-image-2)

- модель `gpt-image-2`, `quality="high"` (плотный текст/детали — нам надо high);
- `n` — только для вариантов эталона (выбрать лучший), страницы идут по одной;
- `input_fidelity` НЕ используется — на gpt-image-2 он не работает, идентичность
  держится сама;
- каждый вызов API = один файл, поэтому анти-коллажная шапка в промпте не нужна.

## Структура

```
config.json            языки, голос, модель, размеры — всё меняется здесь
book.json              мастер-контент: сцены + русский текст + флаг персонажа
pipeline/
  common.py            зафиксированные куски промпта (стиль/текст-зона/preserve)
  gen_anchor.py        2. эталон персонажа (ручной выбор)
  gen_images.py        3. иллюстрации страниц (общие) → webp 820
  qa_vision.py         4. авто-QA зрением Claude (верх пуст? персонаж совпал?)
  translate.py         5. перевод текста на языки (строго 1:1, с лимитом длины)
  tts.py               6. озвучка по языкам (ElevenLabs) + обрезка тишины
  build_manifest.py    7. сборка book_data.js (картинки общие, текст/аудио по языку)
run.py                 запуск автоматических шагов одной командой
reader.html            ридер: листалка, переключатель языка, озвучка
img/  audio/  translations/   ассеты и промежуточные данные
```

## Запуск

Ключи окружения:
```
export OPENAI_API_KEY=...        # картинки (gpt-image-2)
export ANTHROPIC_API_KEY=...     # QA + перевод (Claude)
export ELEVENLABS_API_KEY=...    # озвучка
```
Нужен установленный `ffmpeg` (обрезка тишины) и `pip install openai anthropic elevenlabs Pillow`.

```
# 1) ручной гейт — эталон персонажа
python pipeline/gen_anchor.py
mv img/_anchor_2.png img/_anchor.png      # выбрать лучший из кандидатов

# 2) весь автоматический конвейер
python run.py                              # картинки → QA → перевод → озвучка → сборка
#   варианты:
python run.py --no-tts                     # без озвучки (быстрый визуальный прогон)
python run.py --build                      # только пересобрать book_data.js

# 3) открыть результат
#   в reader.html раскомментировать <script src="book_data.js"> и удалить demo-блок
open reader.html
```

Точечная перегенерация по итогам QA:
```
python pipeline/gen_images.py 8 12         # перерисовать только страницы 8 и 12
```

## Два честных ручных гейта

1. **Выбор эталона** — вкус, не автоматизируется.
2. **Приём QA** — Claude помечает проблемные страницы, решение за человеком
   (но это «глянуть список один раз», а не вычитка каждой).

Всё остальное, включая верх воронки (Claude может сам написать `book.json` по
теме), автоматизируется.

## Новая книга

Скопируй папку, замени `book.json` (сцены + текст + флаги) и описание эталона,
поправь `config.json` при необходимости — конвейер тот же.

## Озвучка: один диктор на все языки

По умолчанию `single_voice_all_languages: true` — один мультиязычный голос
ElevenLabs во всех изданиях (консистентнее). Можно задать свой голос на язык
в `config.tts.voice_by_language` (например, Marina v3 на `ru`). Впиши свои
`voice_id` вместо заглушек `REPLACE_...`.

## Ридер

- листание: тап по правой/левой половине, свайп или стрелки;
- кнопка play: если есть готовая озвучка из манифеста — играет её; если нет —
  читает текст голосом устройства (Web Speech). Поэтому «читаешь сам / читает
  диктор» работает сразу, а ElevenLabs-аудио — это апгрейд качества;
- шрифт текста автоматически уменьшается, если язык длинный, чтобы не залезть
  на картинку.

Для офлайн-продакшна шрифт и картинки лучше встроить (base64), как в остальных
наших ридерах.
