# memory-triples — мемори по тройкам (и по парам)

Обычное мемори учит одному соответствию: флаг ↔ название. Тройка заставляет
держать в голове **три представления одного объекта сразу** — у «Стран мира»
это контур, флаг и название. Размер группы задаёт колода: `2` — привычные
пары, `3` — тройки.

Механика про содержимое **не знает**: лицо карточки рисует колода колбэком.
ES5, без зависимостей, CSS вставляет сама.

## Подключение

```html
<script src="game.js"></script>                                  <!-- задаёт window.MEMORY_TRIPLES -->
<script src="../../../core/mechanics/memory-triples/memory-triples.js"></script>
<script>MemoryTriples.mount(document.getElementById("game"));</script>
```

## Контракт: `window.MEMORY_TRIPLES` до подключения механики

| поле | тип | по умолчанию | что делает |
|---|---|---|---|
| `items` | array | — | пул объектов колоды (обязательно) |
| `kinds` | `string[]` | — | виды лиц карточки, например `["shape","flag","name"]` |
| `perGroup` | number | `kinds.length` | карт в группе: 2 — пары, 3 — тройки |
| `groups` | number | `4` | сколько групп в партии |
| `keyOf` | `fn(item)` | — | ключ группы (у нас — `iso` страны) |
| `render` | `fn(host,item,kind)` | — | колода рисует лицо карточки в `host` |
| `labels` | object | русские | `found / moves / done / moves2 / again / back / aria` |
| `backHref` | string | — | куда ведёт кнопка «Назад» на финале; без неё кнопки нет |
| `onOpen` | `fn(item,kind)` | — | карточку открыли |
| `onMatch` | `fn(item)` | — | группа собрана (у нас звучит название страны) |
| `onDone` | `fn({moves,groups,stars})` | — | партия закончена |

## Наружу

```js
MemoryTriples.mount(hostEl)   // false, если контент не задан
MemoryTriples.start()         // новая раздача
MemoryTriples.again()         // то же самое, для кнопки «↻»
MemoryTriples.stats()         // {moves, found, groups, per}
MemoryTriples._keys()         // раскладка колоды — только для автотестов
```

## Решения, которые стоит помнить

- **Промах не прячется сразу**: открытые карточки подсвечиваются красным и
  висят ~1 с. Мгновенный откат превращает игру в лотерею — ребёнок не успевает
  разглядеть, что именно открыл.
- **Колонок ровно столько, сколько карт в группе.** Строка по ширине равна
  одной тройке, и правило «собирать по три» видно из раскладки.
- **Скрытые лица рисуются сразу**, при раздаче: подставлять контент в момент
  переворота — значит показать пустую карточку на время загрузки картинки.

## Тип задания и прогресс

Тип — `pairs` из общего набора (`docs/engine-contract.md`). Прогресс механика
**не пишет**: это тренажёр-повторение, счёт живёт внутри партии. Колода может
записать свой прогресс из `onDone`.
