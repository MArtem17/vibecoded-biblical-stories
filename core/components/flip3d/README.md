# core/components/flip3d — общий движок 3D-флеш-карт

Карточка в настоящем объёме: толщина, скруглённые углы, блик, мягкая тень и
колода за спиной. Нажатие переворачивает, протяжка листает, наклон при
протяжке даёт параллакс. Один движок на все колоды — про конкретную колоду он
**не знает**.

```
flip3d/
  engine.js   ← движок (сцена, карта, ввод, кэш текстур). ОДИН на все колоды.
  README.md
```

three.js берём общий — `core/vendor/three-r128/three.min.js` (UMD, глобальный
`THREE`). Третью копию библиотеки не заводим.

## Контракт: `window.FLIP3D` до подключения `engine.js`

| поле | тип | по умолчанию | что делает |
|---|---|---|---|
| `count` | number | — | сколько карт в колоде (обязательно) |
| `index` | number | `0` | с какой карты начать |
| `aspect` | number | `2/3` | ширина/высота карты |
| `texW` | number | `640` | ширина текстуры в px (высота — по `aspect`) |
| `theme` | `{edge,stack}` | кремовые | цвет торца карты и карт колоды за спиной |
| `margin` | `{w,h}` | `{1.30,1.14}` | поля вокруг карты (доля от её размера) |
| `speed` | number | `1` | общая скорость движений (переворот, полёт, «подскок») |
| `drawFace` | `fn(ctx,w,h,i,done)` | — | нарисовать **лицо** карты `i` |
| `drawBack` | `fn(ctx,w,h,i,done)` | — | нарисовать **изнанку** карты `i` |
| `onIndex` | `fn(i)` | — | сменилась карта |
| `onFlip` | `fn(i,isBack)` | — | карту перевернули |

Колода рисует обычным 2D-канвасом и не думает о форме: **скругление углов
делает движок** маской, идемпотентно. Поэтому картинки можно догружать и
перерисовывать карту сколько угодно раз — каждый раз зовите `done()`:

```js
window.FLIP3D = {
  count: LIST.length,
  drawFace: function(ctx,w,h,i,done){
    ctx.fillStyle="#FFFDF9"; ctx.fillRect(0,0,w,h);
    var im=new Image();
    im.onload=function(){ ctx.drawImage(im,0,0,w,h*0.4); done(); };  // догрузилось — зовём done
    im.src=LIST[i].flag;
    done();                                                          // и сразу, чтобы не ждать
  },
  drawBack: function(ctx,w,h,i,done){ /* … */ done(); }
};
```

## Наружу

```js
Flip3D.mount(canvasEl)   // старт; false, если THREE не загрузился
Flip3D.next() / prev()   // листать с анимацией полёта
Flip3D.flip()            // перевернуть
Flip3D.go(i)             // прыжок на карту i без полёта
Flip3D.index() / count() / flipped()
Flip3D.settling()        // идёт ли ещё движение (карта всё время чуть «дышит»,
                         // по кадрам конец анимации не определить)
Flip3D.rotYDeg()         // текущий угол переворота в градусах (для проверок)
Flip3D.repaint()         // перерисовать текущую карту (смена языка)
```

## Что движок делает сам

- **Кэш текстур** на 7 ближайших карт, дальние освобождает; соседние карты
  рисует заранее, чтобы переход не спотыкался о загрузку картинок.
- **Скругление углов** маской по канвасу колоды.
- **Ввод**: протяжка (порог 56 px или быстрый бросок 30 px), нажатие —
  переворот, стрелки и пробел с клавиатуры.
- **Посадку камеры** под любой экран: карта вписывается и по высоте, и по
  ширине, пересчёт на resize и повороте устройства. Запас вокруг карты по
  умолчанию 1.30 по ширине и 1.14 по высоте — в нём видно колоду за спиной и
  уезжающую карту при листании. Если карта — главное на экране, а не часть
  сцены, запас можно поджать через `margin`: на телефоне 1.30 отдаёт полям
  четверть ширины, и карта упирается в ширину задолго до высоты (так фото в
  `decks/slovar-na-stsenah/flip3d` выходило вдвое мельче возможного). Меньше
  ~1.05 не ставить: карта начнёт срезаться на краях при протяжке.

## Два прохода отрисовки — не трогать

Колода за спиной и тень рисуются **отдельным проходом** (слой 1), между
проходами чистится буфер глубины, и только потом рисуется карта (слой 2).
Свести это обратно в один `ren.render(scene,cam)` нельзя.

Причина. Колода лежит в 0.055–0.11 позади карты, а карта на перевороте
выметает по глубине до полуширины — в двадцать раз больше зазора. На середине
переворота дальняя половина карты физически уезжает ЗА колоду, и колода её
честно закрывает: на экране пропадает половина текста и фотографии, карта
выглядит обрезанной по вертикали. Отодвинуть колоду не выход — она на то и за
спиной, чтобы лежать вплотную; поэтому она стала задником, а не объектом сцены.

Дефект прожил в движке до 04.08.2026 и найден владельцем глазами на живом
прогоне («неправильно делается flip»). Ни один прогон его не видел: на
статичном кадре карта цела, в коде ничего не выглядит подозрительно, а живёт
поломка ~200 мс в середине анимации. Проверка — `tools/node/check_flip3d.js`:
монтирует движок на фикстуре «карта целиком пурпурная» и меряет площадь
пурпурного по ходу переворота — она обязана падать как `|cos θ|`. На старом
движке проверка показывает 62–71 % от ожидаемого, на исправленном — 100–107 %.

## Инварианты

- **ES5, без шага сборки** — как и весь рантайм платформы.
- Фон сцены прозрачный (`alpha:true`): светлый фон задаёт страница, чтобы не
  нарушать правило высокого контраста.
- Логика — только здесь. Колода несёт тонкий `index.html` + свой файл с
  отрисовкой карт. Движок в колоду **не копируем**.
