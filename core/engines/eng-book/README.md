# core/engines/eng-book — движок «Интерактивный учебник»

Общий движок ученических интерактивных учебников платформы (иностранные языки,
предметные курсы). Перенесён из отдельного проекта `eng5klass`. Не знает про
конкретную колоду — контент задаёт колода.

## Что даёт движок
- Рендер книги: главный бар, оглавление, страницы-развороты (`.sheet`), листалка.
- ~40 механик упражнений в объекте `EXTYPES` (по одному рендереру на тип).
- Общие проверка/ответы/сброс: `checkEx` / `answersEx` / `resetEx`, счёт, штамп.
- Озвучка слов (Web Speech `speechSynthesis`) и распознавание речи для говорения.

## Разделение (ядро ↔ колода)
- **Ядро (`core/engines/eng-book/`)** — `engine.js`, `book.css`, `fonts.css` +
  `fonts/` (Rubik / Golos Text / Caveat, вшиты офлайн base woff2, без CDN).
- **Колода (`decks/<slug>/`)** — только `data/*.json` (юниты) и `img/*`
  (сцены и иконки). Тонкий `index.html` колоды подключает css/js из ядра и
  задаёт свой список юнитов через `window.BOOK_MANIFEST`.

```html
<link rel="stylesheet" href="../../core/engines/eng-book/fonts.css">
<link rel="stylesheet" href="../../core/engines/eng-book/book.css">
<script>window.BOOK_MANIFEST = ['data/starter.json','data/unit1.json', …];</script>
<script src="../../core/engines/eng-book/engine.js?v=1"></script>
```
Разметка `<body>` (topbar / tocov / viewport+rail) — как в эталонной колоде
`decks/angliyskiy-5/index.html`.

## Контракт контента
Юнит = **5 страниц** (Vocabulary / Reading / Grammar / Listening·Writing /
Check it), на странице **6–8 упражнений**. Блоки страницы (`t`): `rule`, `sub`,
`img`, `photorow`, `readcard`, `refpanel`, `culture`, `totalbar`, `ex`.
Упражнение — `{t:"ex", id, num, type, title, en, …}`; `type` — ключ из `EXTYPES`.
Полное описание блоков и полей каждой механики — в `data/`-примерах колоды и в
истории проекта eng5klass. Правильные ответы пишутся в естественном порядке —
движок сам перемешивает варианты при показе.

## Инвариант
Правки рендера/механик — только здесь, в ядре, чтобы менялись все колоды сразу.
Контент правится только в `decks/<slug>/data/` — код не трогаем, пока не нужен
принципиально новый тип задания (тогда добавляем рендерер в `EXTYPES`, старые
не ломаем). При правке движка поднять `?v=` у `engine.js` в `index.html` колоды.

## Тест инвариантов (гонять перед PR при правке движка или контента)
```bash
npm i jsdom --no-save && node tools/node/test-eng-book.js [decks/angliyskiy-5]
```
Успех — «страниц: 55 | упражнений: 341 | ВСЁ ЗЕЛЁНОЕ ✓», иначе список проблем и
код выхода 1 (мёрджить нельзя). Проверяет: валидность JSON, решаемость каждого
упражнения («Ответы» → полный балл, «Сбросить» → 0, подсказка не хвалит),
коридор 6–8 упражнений на страницу, уникальность id, наличие картинок, плюс
структурные ловушки по типам (дубли в lines, пул покрывает ответы, пересечения
кроссворда, один правильный вариант в radio/dialog и т.д.). Это платформенная
адаптация `test.js` из eng5klass (апстрим-копия — `decks/angliyskiy-5/tools/test.js`).

## Эталонная колода
`decks/angliyskiy-5/` — интерактивный учебник английского, 5 класс.
Этот же контент — канонический источник для учительского кабинета: презентации,
КИМ, рабочие листы и ДЗ генерируются из юнитов (`data/*.json`).
