# Контракт движков `core/engines/`

Полное описание — [`../../docs/engine-contract.md`](../../docs/engine-contract.md).
Здесь — краткая памятка по самим движкам.

## Движки

| Движок | Платформа | Назначение |
|--------|-----------|------------|
| `school-es5` | ES5 | школьный возраст |
| `preschool-es6` | ES6 | дошкольники |
| `sandbox-es5` | ES5 | песочница / свободные симуляции |
| `geo5klass` | — | географические симуляции (карта + профиль высот и т.п.) |
| `rech-deck-kit` | ES5 | озвученные речевые колоды серии «Речь» (Болталки, Бормоталки): колода подключается данными (content.js + DECK_CONFIG), логопедический слой включается полями group/color/sound |

Выросли органически под разные задачи. Работают, но дублируют логику.

## Общий контракт (что обязан давать любой движок)

- точка входа `play.html?w=NN`, контент карты — `cards/NN.js`;
- показ ассета карты с эмодзи-фолбэком;
- озвучка: проигрывание аудиофайла с фолбэком на синтез;
- отметка выполнения карты (прогресс);
- типы заданий: `intro / single / multi / pairs / sort / sim`.

## Правило сведения

Не сводить в один движок одним махом. Сначала все колоды — на общий контракт,
затем постепенное сведение без ломки контента (план §5 в
`../../docs/architecture.md`).
