# Прототип механик · ОМ «Семья»

Интерактивный **прототип-витрина** игровых механик для дошкольной ступени
«Образовариума» (ОМ). На примере темы **«Семья» / «карта 05»** в одной странице
собраны ~40 мини-механик: от перетаскивания подписей до симуляторов и
многослойной карты. Это рабочая «песочница» для дизайна занятий — посмотреть,
как ощущается каждая механика на телефоне, и собрать из них маршрут.

> Внутренняя версия: `master_proto_OM_v22` · в шапке помечена как «прототип механик».

Приложение полностью клиентское и **офлайновое**: один `index.html`, два
самостоятельных JS-движка и набор картинок `.webp`. Ни сборки, ни сервера, ни
зависимостей — достаточно открыть файл в браузере.

---

## Как запустить

```bash
# просто открыть файл
open master-proto-om/index.html        # macOS
xdg-open master-proto-om/index.html    # Linux

# или поднять любой статический сервер (удобнее для мобильной отладки)
cd master-proto-om && python3 -m http.server 8000
# затем http://localhost:8000
```

Открывать лучше на телефоне или в мобильном режиме браузера (ширина макета —
до 560 px), все механики рассчитаны на тач. Работает без интернета.

## Как это устроено

```
master-proto-om/
├── index.html          # вся витрина: разметка задач + инлайновая логика механик
├── labeldrag.js / .css # движок «перетащи название на деталь» (автономный)
├── buildword.js / .css # движок «собери слово из букв» (автономный)
├── *.webp              # фоны, сцены, иконки предметов и зверей
└── icons_src/          # исходные иконки (30 предметов одним листом + по штуке)
```

- **`index.html`** — единственная страница. Каждая механика оформлена карточкой
  `.taskcard` с плашкой-«китчем» (`НОВОЕ ЗАДАНИЕ` / `НОВАЯ МЕХАНИКА` /
  `СИМУЛЯТОР` / `КНИЖКА` / `ИГРА`), заголовком и инструкцией. Логика почти всех
  механик написана инлайн в одном `<script>` (ES5, без фреймворков): `<canvas>`
  для симуляторов и рисования, обычный DOM + события указателя для остального.
- **Два движка вынесены в отдельные модули** (`LabelDrag`, `BuildWord`) — их
  можно переиспользовать в других колодах. Оба извлечены и отлажены из
  «взрослой» колоды [«Как всё устроено»](../README.md) и доведены до
  самодостаточных интерактивов.
- **Озвучка** в прототипе — заглушка: `ttsSay()` просто пишет реплику в консоль.
  В бою сюда подключается синтез речи / готовые аудио.

## Каталог механик

Витрина сгруппирована по типам. Всего 36 карточек-заданий.

### Перетаскивание и слова
| Механика | Что делает ребёнок |
|---|---|
| **LabelDrag · фишки-предметы** («Что где лежит») | тащит картинку-фишку на нужное место комнаты |
| **LabelDrag** («Кто есть кто в семье») | подписывает членов семьи на картинке |
| **BuildWord** («Собери слово») | собирает слово из перемешанных букв |

### Монтессори / «найди и покажи»
| Механика | Суть |
|---|---|
| **Чья тень?** | сопоставить предмет с его силуэтом |
| **Найди и покажи** (виммельбух) | найти объекты на насыщенной сцене |
| **Открой окошко** (lift-the-flap) | открыть дверцу — кто за ней |
| **Чей голос?** (звуковая книжка) | выбрать, кто так звучит |
| **Шторка «было/стало»** | потянуть штору: день ↔ ночь |
| **Проведи дорожку** (лабиринт) | провести мальчика к кровати |
| **Фонарик** | подсветить тёмную сцену лучом |
| **Виммельбух-счёт** | сосчитать мячики / машины на улице |
| **Что изменилось?** | найти, что пропало |
| **Найди пару** (мемори) | классическая память на карточках |
| **Времена года** (свайп) | пролистать сезоны |

### Симуляторы (ползунки / жест)
Один-два ползунка меняют сцену в реальном времени (отрисовка на `<canvas>`):
**превращения воды** · **день и ночь** (покрути пальцем) · **что вырастет?**
(два ползунка) · **времена года** · **солнце и тень** · **погода** ·
**смешай краски**.

### Книжка с заданиями (КНИЖКА)
Полистная мини-книжка на одном движке (`initPickBook` / `initBook`) с разными
типами разворотов: «Кто это?», «Прогулка», «Мой день», «Закончи фразу»,
«Читаем и ищем», «Волшебное слово», «Кто как говорит», «Теремок»,
«Большой и маленький», «Чей домик?», «Сколько?», «Что любит?», «Один — много»,
«Сказка про утёнка».

### Многослойная карта и игры на колоде
Одна карта несёт несколько слоёв — **масть 🐾**, **число 🔢**, **цвет 🎨**,
**событие ⭐**. Слои включаются/выключаются; в каждой игре «главным» становится
свой слой:

- **Игра 1 · По порядку** — нажимать карты по возрастанию числа.
- **Игра 2 · Собери масть** — собрать все карты одной группы.
- **Игра 3 · Найди по цвету** — для малышей, без чтения: тапнуть все карты с
  нужной рамкой.
- **Игра 4 · Ходилка** — карты как клетки поля: кубик, фишка, карты-события.

### Комбо-сценарии
**Маршруты занятий** — готовые связки блоков по нарастанию сложности:
`узнал → поиграл → понял причину → закрепил чтением → проверка`. Шаг маршрута
открывает реальный блок и возвращает обратно.

## Движки

### LabelDrag — «перетащи название на деталь картинки»
Автономный ES5-модуль без зависимостей (`labeldrag.js` + `labeldrag.css`).

```js
var game = LabelDrag.mount(elem, {
  image:  'assets/plant.webp',
  aspect: '3/4',
  wide:   false,              // false → подписи слева/справа, true → сверху/снизу
  parts: [
    { id:1, word:'Цветок', ax:50, ay:19, side:'r', cmt:'Самая красивая часть…' },
    // ax/ay — координаты пина в % от размера картинки
  ],
  onComplete: function(){ /* все детали подписаны */ }
});
game.reset();    // начать заново
game.relayout(); // пересчитать раскладку (например, после показа блока)
game.destroy();  // снять обработчики
```

### BuildWord — «собери слово из букв»
Автономный ES5-модуль (`buildword.js` + `buildword.css`).

```js
var w = BuildWord.mount(elem, {
  words: [ { word:'dog', hint:'собака', image:'img/dog.webp' }, 'cat', 'sun' ],
  uppercase:   true,
  anchorFrom:  6,   // у слов длиной ≥ N подставлять первую букву опорой
  distractors: 0,   // сколько лишних букв добавить в банк
  maxAttempts: 2,   // промахов до автопоказа ответа
  onComplete: function(score){ /* score = {clean, total} */ }
});
```

Тап по букве ставит её в первый пустой слот, тап по слоту — возвращает в банк.
Верно собрано → зелёная вспышка и следующее слово; ошибка → слоты «трясутся»,
со второго промаха слово показывается целиком («запомни»).

## Ассеты

Все изображения — `.webp` для лёгкого веса:

- **Сцены и фоны:** комната (`bedroom_day/night`), двор по сезонам
  (`yard_spring/summer/autumn/winter`), улица, парк, лабиринт, виммельбух.
- **Иконки предметов и зверей:** `apple`, `ball`, `cat`, `dog`, `bus`, `car`…
  (исходники — в `icons_src/`, в т.ч. лист из 30 иконок).
- **Кадры симуляторов:** вода (`water_ice/liquid/boil`, `sim_*`), рост растения
  (`grow0…grow4`), Земля день/ночь (`earth_a/b`).

---

## Статус

Это **прототип**, а не продакшен: цель — быстро пощупать механики и собрать из
них сценарии занятий. Озвучка замокана, часть данных захардкожена прямо в
`index.html`. Переиспользуемое ядро — движки `LabelDrag` и `BuildWord`.
