# core/ — общее ядро платформы

Здесь живёт всё, что **переиспользуется колодами**: движки и механики. Ядро не
знает про конкретные колоды — оно предоставляет контракт, а колода подключает
его и кладёт сверху свой контент.

```
core/
├── engines/    движки рендеринга/интерактива (16 штук)
│   ├── school-es5/      ES5, школьный возраст
│   ├── preschool-es6/   ES6, дошкольники
│   ├── sandbox-es5/     ES5, песочница/симуляции
│   ├── geo5klass/       движок географических симуляций
│   ├── book/            озвученные цифровые книги
│   ├── flipbook/        листалка картинок из PDF, без звука
│   ├── encyclopedia/    интерактивная книга-энциклопедия (5 языков, караоке, хотспоты)
│   ├── rech-deck-kit/   озвученные речевые колоды серии «Речь» (+ общий deck.css)
│   ├── quest/           сюжетные тома-игры (docs/product-quest.md)
│   ├── feed/            лента-энциклопедия, BKT-мастерство (docs/product-feed.md)
│   ├── board/           доски уроков (docs/board-slides-contract.md)
│   ├── chess-tutor/     шахматный наставник: 0x88, ИИ, BKT
│   ├── eng-book/        колоды «Английский 5/6/7»
│   ├── eng-vocab/       словарные тренировки
│   ├── reading/         читалка
│   ├── skeleton3d/      3D-скелет
│   └── _CONTRACTS.md    общий контракт движка
├── mechanics/  библиотека мини-игр и механик
│   └── _CONTRACTS.md    контракты механик: новые добавляем, старые не ломаем
├── components/ переиспользуемые UI-виджеты (не привязаны к колоде)
│   └── globe/          вращающийся глобус на <canvas> (ES5, без зависимостей)
├── fonts/      шрифты (в т.ч. Nunito, встроенный base64 для офлайна)
├── fx/         визуальные эффекты
├── kit/        общий UI-кит
└── vendor/     сторонние библиотеки
```

## Правила

- **Не копировать ядро в колоды.** Колода подключает движок/механику из `core/`.
- **Не ломать существующие механики и контракт заданий** ради одной колоды
  (`mechanics/_CONTRACTS.md`).
- Движки пока **не** сводятся в один: высокий риск. Держим как есть,
  фиксируем общий контракт, рефакторим постепенно (план §9 в
  `../docs/architecture.md`).

## Статус

Ядро — **рабочий код, а не каркас**: движки собраны и стоят под боевыми колодами
(эталон движка — «Окружающий мир», эталон энциклопедии — `decks/dinozavry`,
эталон ленты — `decks/telo-cheloveka/feed`). Сведение движков в один по-прежнему
идёт поэтапно — см. план рефакторинга в `../docs/architecture.md` §9.

Контракт движка для агентов — [`../docs/engine-contract.md`](../docs/engine-contract.md).
