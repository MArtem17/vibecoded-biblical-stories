# engine: geo5klass

Движок географических симуляций (карта + профиль высот, синхронный маркер,
разрезы и т.п.). Используется колодой «География 5–6». Код мигрирует при переносе
колоды. Общий контракт — [`../_CONTRACTS.md`](../_CONTRACTS.md).

Статус: плейсхолдер, ожидает миграции (план §1, §5 в `../../../docs/architecture.md`).
