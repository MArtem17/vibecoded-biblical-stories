# rech-deck-kit — движок колод серии «Речь»

Общий движок озвученных речевых колод: «Болталки со звуком» (0–3),
«Бормоталки · чистоговорки» (3–5), «Читаем по слогам» (4–6),
«Связная речь · истории по картинкам» (4–7), «Фонетика · звуковой
разбор» (6–8). ES5, офлайн, высокий контраст (чёрное на белом),
только «нажми». Все слои включаются данными; в одной колоде активен
один режим (по приоритету: истории → слоги → разбор → базовый).

## Подключение (колода — данными, без правок движка)

Тонкий `decks/<slug>/index.html`:

```html
<link rel="stylesheet" href="../../core/engines/rech-deck-kit/deck.css">
<script src="content.js"></script>          <!-- window.DECK_CONTENT -->
<script>window.DECK_CONFIG={...};</script>  <!-- конфиг колоды -->
<script src="../../core/engines/rech-deck-kit/deck.js"></script>
```

`DECK_CONFIG`: `title`, `subtitle`, `logo` (эмодзи шапки),
`cover` (путь к обложке — включает заставку «Начать»; нет — заставки нет),
`startHint` (подпись под кнопкой заставки),
`printHref` (кнопка 🖨 в шапке → печатный вид),
`docHref` (кнопка 📖 в шапке → вкладыш-методичка PDF; собирается
`tools/python/build_rech_vkladysh.py`, методика серии — docs/rech-series.md).

`DECK_CONTENT` — сгенерирован из `content.json` колоды
(`window.DECK_CONTENT={...}` — офлайн-загрузка без fetch). Формат:
`cards` — плоский список записей «карта+сторона» (`id`, `side:"a"/"b"`,
`syllable`, `verse`, `image`, `audio`); звуковые карты «Болталок» —
`type:"sounds"`, `title`, `items[4]` (`label`/`image`/`audio`).

## Базовое поведение

Заставка (если есть `cover`) → иконостас 3 колонки → карта крупно:
слог + ▶ в строке, картинка, текст. Переворот a/b — нажатием по самой
карте (кнопки переворот не вызывают), озвучка ▶ по нажатию.
Звуковая карта — сетка 2×2, картинка играет своё слово-звук,
переворот — нажатие рядом (название/фон).

## Логопедический слой (включается наличием полей в данных)

Если у записей есть `group`+`color` (и в корне контента `sound_groups`/
`sound_colors`):
- цветная метка звука на плитке и чип «Звук N» на карте;
- фильтр по группе звуков над иконостасом (+ точечно по звуку,
  если есть поле `sound`);
- подсветка целевой буквы (поле `sound`) в тексте цветом группы;
- режим «🗣 Повтори за диктором»: play → пауза → индикатор «Твоя очередь!»
  (без записи, просто ритм).

У «Болталок» этих полей нет — слой не включается, поведение прежнее.

## Слой звукового разбора (включается массивом `sounds` в данных)

«Фонетика · звуковой разбор» (6–8): карты-слова с посимвольной схемой
`sounds: [{L, S, c, voiced|stress}]` (йотированные — два звука, у второго
`L` пустое). Иконостас группируется разделами по `level` (1–4); печатные
карты — плиткой с картинкой, цифровые слова — плиткой-словом. Карта — режим
интерактивного разбора: пустые кружки (нажатие красит по циклу
красный/синий/зелёный, нажатие над кружком — ударение) → «Проверить» →
✓/✗ по звукам + эталон; чекбокс «показывать схему»; ▶ играет слово целиком
и по слогам. Переворот в этом режиме отключён (у слова нет сторон).

Рендер схемы — общий модуль **`schema.js` + `schema.css`** (подключаются
страницами колоды дополнительно к deck/print): экран (px) и печатный вид
(контейнерные cqw). Python-близнец рендера — в
`tools/python/build_print_cards.py` (печатные JPG лицо+оборот и
`--oborot-pdf` — A4/150dpi, 4 оборота на страницу).

## Слоговый слой (включается типами `letter`/`syllable` в данных)

«Читаем по слогам» (4–6): иконостас с разделами «Буквы / Слоги / Слова».
Карта-буква — крупная буква (`letter`, `color`: hex — цвет класса,
`"diagonal_blue_green"` — диагональная сине-зелёная метка согласной) +
картинка + ▶; переворот показывает букву-«сестру». Карта-слог —
двухцветный слог во весь экран (`cons` синий + `vowel` красный) + ▶.
Карта-слово — `syllabified` (МА-ЛИ-НА) + картинка + ▶.
**Конструктор слов** (кнопка над сеткой, включается массивом
`constructor_words: [{word, syllables[]}]` в корне контента): образец →
слоты + пул слогов с дистракторами → тап-заполнение → автопроверка →
озвучка собранного слова (если слово есть на карте) → «Ещё слово!».

## Слой историй (включается полями `story`+`frame` в данных)

«Связная речь · истории по картинкам» (4–7): записи карт односторонние
(`story`, `story_title`, `frame`, `of_frames`, `color`, `question`,
`vocab[]`, `image`, `q_audio` — озвучка вопроса-опоры, даёт кнопку ▶ у
вопроса; генератор tools/python/gen_istorii_questions.py), в корне контента — `stories_list:
[{key, title, color, frames, story, audio}]`. Иконостас — плитка на
историю (кадр 1 + цветная метка + название). Открытие — режим
**«Собери историю»**: слоты 1..N + перемешанный пул кадров, тап ставит
кадр в первый свободный слот, автопроверка порядка по `frame`; после
верной сборки — вопросы-опоры со словариками по каждому кадру и кнопка
«▶ Послушай, как рассказал диктор» (эталон — ПОСЛЕ детской версии).
Переворота карт в этом режиме нет.

## Прогресс и сквозные элементы

`DECK_CONFIG.progressKey` включает прогресс (localStorage, формат
docs/progress.md: `{"01":true,…}`): счётчик «✓ пройдено N из M» в шапке,
галочка на плитке (`data-pid`), кнопка «Сбросить прогресс» внизу сетки.
Отметка: прослушивание карты (▶), верный разбор (Фонетика), собранная
история (все кадры), собранные слова конструктора — вспомогательный ключ
`<progressKey>_words`. `DECK_CONFIG.nextDeck {title, age, href, cover}` —
карточка «Дальше по серии» в конце иконостаса.

## Игровые режимы (кнопки над иконостасом)

- базовая колода: «🎧 Слушать подряд» (карусель всех сторон); при парах
  одинаковых `label` в звуковых картах — «🔔 Что ещё так звучит?»
  (звук → найди вторую картинку); при поле `sfx` у items — «🎵 Угадай звук»
  (НАСТОЯЩИЙ звук предмета → найди картинку из 4, награда — звукоподражание
  голосом; файлы генерирует tools/python/gen_boltalki_sfx.py);
- логопедическая: «🎤 Концерт» — 5 случайных чистоговорок текущего фильтра
  (эталон → «твоя очередь» → дальше, финал-праздник);
- слоговая: «📖 Прочитай сам» (слог без звука → проверка озвучкой) +
  чекбокс «показывать образец» в конструкторе;
- разбор: «🏁 Марафон» — 10 случайных слов подряд со счётом.

## Печатный вид (print.html)

Просмотрщик карт в печатной раскладке — `decks/<slug>/print.html`
(тонкая страница: `print.css` + `content.js` + `DECK_CONFIG` + `print.js`).
Рендерит все стороны как печатные макеты (пропорция 76:111, раскладка
как в `tools/python/build_print_cards.py`); печать браузером даёт
1 карту = 1 страницу 76×111 мм. Кнопка 🖨 в шапке приложения включается
конфигом `printHref:"print.html"`.
