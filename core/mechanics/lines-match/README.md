# lines-match — «верёвочки»

Тап по элементу слева, тап по элементу справа — между ними тянется линия.
Тап по любому концу уже связанной пары освобождает её для новой связки.
«Проверить» красит линии и рамки разом по всей доске.

Не путать с `type:'lines'` в `core/engines/eng-book/engine.js` — той же идеей,
но вплетённой в реестр упражнений движка книг и держащей восемь юнитов
«Английского 5». Этот модуль — независимая реализация того же приёма для
движков без общего реестра `checkEx`. Свести их в один код — задача на
будущее (см. заголовок `lines-match.js`), не сделанная сейчас намеренно,
чтобы не рисковать готовым контентом ради рефакторинга.

## API

```js
var handle = LinesMatch.mount(container, pairs, opts);
```

- `container` — пустой DOM-элемент, механика сама наполняет его и заводит
  свой CSS (один раз на страницу, id `lnm-css`).
- `pairs` — `[[left, right], …]`. Строки должны быть уникальны в пределах
  раунда: механика ищет элементы по значению (`data-val`), совпадающие
  строки будут неразличимы.
- `opts.shuffleRight` — по умолчанию `true` (правая колонка перемешивается).
  `false` — оставить порядок как в `pairs`.
- `opts.leftLang` / `opts.rightLang` — код языка (BCP47), ставится атрибутом
  `lang` элементам своей колонки. Колонки почти всегда на разных языках.
- `opts.onCheck(result)` — вызывается из `handle.check()`, ПОСЛЕ того как
  визуал уже перекрашен: `{good, total, items:[{l, r, ok}]}`.

`handle`:
- `.check()` — считает результат, красит связки зелёным/красным, блокирует
  дальнейшие клики; возвращает тот же объект, что уйдёт в `onCheck`.
- `.reset(newPairs?)` — новый раунд (без аргумента — тот же набор пар,
  правая колонка тасуется заново).
- `.destroy()` — снимает разметку и класс `lnm` с контейнера.

## Вид

Своя палитра через CSS-переменные (`--lnm-ink`, `--lnm-muted`, `--lnm-line`,
`--lnm-ok`, `--lnm-bad`, `--lnm-accent`, `--lnm-soft`, `--lnm-badsoft`) со
значениями по умолчанию. Хост-страница может переопределить их у предка
контейнера обычным CSS — JS-настройки темы не требуется. Шрифт —
`font-family:inherit`, берёт шрифт страницы.

Кнопки «Проверить» / «Ещё раз» модуль не рисует — это решает вызывающий код
(в `decks/slovar-na-stsenah` они те же кнопки `.btn`, что и у остальных
заданий продукта).
