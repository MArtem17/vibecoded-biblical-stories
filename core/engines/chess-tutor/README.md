# core/engines/chess-tutor — движок «настолка + наставник» (шахматы)

Переиспользуемый цифровой слой тайтлов формата «настолка + наставник»:
объясняет навык карты, тренирует адаптивно, даёт сыграть против ИИ «под уровень»
и судит партию двух людей. Шахматный — но устроен как **общее ядро + контент
колоды**, чтобы будущие тайтлы (например, «Шашки», v3 ТЗ) переиспользовали каркас.

> Колода (`decks/<slug>/`) несёт только контент: `content/skills.js` (навыки,
> уроки, генераторы заданий) и тонкий `index.html` с конфигом. Логика — здесь.

## Файлы

| Файл | Что делает | Зависит от |
|------|-----------|-----------|
| `chess.js` | Правила: легальные ходы, шах/мат/пат, рокировка, взятие на проходе, превращение, SAN, FEN. Свой ИИ тут не живёт. | — |
| `board.js` | Доска рисуется **кодом** (DOM 8×8), фигуры Стаунтон (Unicode), ввод **PointerEvent** (нажми-нажми и перетаскивание), подсветка/шах/координаты. | — |
| `ai.js` | Соперник «под уровень»: негамакс с ограничением глубины + материально-позиционная оценка + «слепота» (педагогичные зевки). | `chess.js` |
| `bkt.js` | Адаптив Bayesian Knowledge Tracing (Робоборик): P(S)=0.10, P(T)=0.10 (только после верного ответа), P(G) по типу или 1/число вариантов. «Освоено» = P(L)≥0.82 **и** ≥5 заданий **и** 3 верных подряд (защита от угадывания, липкое). | — |
| `tutor.js` | Каркас приложения: экраны, три режима, прогресс (localStorage), родительский экран. | всё выше + контент колоды |

Порядок подключения в HTML: `chess → board → ai → bkt → tutor → content/skills.js → boot`.

## Запуск из колоды

```html
<script src="../../core/engines/chess-tutor/chess.js"></script>
<script src="../../core/engines/chess-tutor/board.js"></script>
<script src="../../core/engines/chess-tutor/ai.js"></script>
<script src="../../core/engines/chess-tutor/bkt.js"></script>
<script src="../../core/engines/chess-tutor/tutor.js"></script>
<script src="content/skills.js"></script>
<script>
ChessTutor.boot({
  mount: document.getElementById('app'),
  title: 'Образовариум · Шахматы',
  progressKey: 'chs_prog',          // уникальный ключ прогресса колоды
  skills: CHESS_SKILLS,             // контент тайтла (см. ниже)
  cardImageBase: 'assets/cards/'    // лица карт NN.webp для хаба
});
</script>
```

## Контракт контента колоды (`config.skills`)

```
{ list: [ skill ], stages: ['Основы','Правила','Тактика','Финал и дебют'] }

skill = {
  n, code, stage(1..4), title, glyph, learn, kind,
  lessons: [ { text, fen, highlight?, orientation? } ],   // объяснение по шагам
  gen: function(level /*1..3*/, rng) -> task               // задание под уровень
}

task (что исполняет каркас):
  ui: 'move' | 'choice' | 'click'
  kind: 'recognize' | 'apply' | 'calc'        // для P(G) в BKT
  prompt, fen, orientation, hint:{squares,text}
  // ui:'move':   check(move, after, before) -> bool ; good, bad ; targetSq?
  // ui:'choice': options:[{label,correct}], explainWrong ; good, bad
  // ui:'click':  target:'e4' ; good, bad
```

Каркас сам: выбирает уровень по освоению (BKT), рендерит доску/варианты,
проверяет ответ, обновляет `P(L)`, открывает ступени, ведёт прогресс.

## Инварианты платформы, которые соблюдает движок

- **ES5 / vanilla / офлайн**, без фреймворков и сборки в рантайме; логика во
  внешних `.js` (лимит инлайн-скрипта iOS ~21 КБ — в оболочке только конфиг).
- **Высокий контраст**, чёрный текст на белом; глагол только **«нажми»**.
- Доски-схемы **рисуются кодом** (позиции всегда верны), не картинками ИИ.
- Прогресс — `localStorage`, единый ключ тайтла (`chs_prog` у шахмат).

## Проверки

- `chess.js` — perft (start/kiwipete/pos3/pos5 сходятся), мат/пат/нотация.
- `ai.js` — берёт бесплатную фигуру, находит мат в 1, играет легально.
- `bkt.js` — сходимость к порогу; симуляция угадывающего: ложное «освоено» ≤ ~20% (было 98% при 2 вариантах).
- Контент колоды — `verify_skills.js`: все 24 навыка дают решаемое задание.
- Сквозной прогон UI под jsdom: экраны рендерятся, ход с ответом ИИ и задание
  Учителя проходят end-to-end.
