# core/engines/quest — движок сюжетного тома-игры

Переиспользуемое ядро для **сюжетных томов-игр** (Библия, мифы, сказки
народов…). Том-инстанс приносит только данные и сцены, движок строит весь UI.

```
core/engines/quest/
  quest.css   дизайн-система (крем/бордо/оранж, тени, тач-кнопки, переходы)
  quest.js    движок: заставка, тропа эпох, альбом, задания, награды/звёзды/
              медали/супер-приз, карта дня, ранги, карты мира, реконструктор,
              встраивание книг, «Свободная игра», родительский режим
  fonts/      брендовый шрифт Nunito (woff2-субсеты, офлайн)
```

## Как собрать новый том за 3 файла

```
decks/<slug>/
  index.html   — 12 строк: подключает quest.css, data/volume.js, sims.js, quest.js
  data/volume.js — window.VOLUME (том: эпохи, карты, ui, карты мира, книги)
  sims.js        — window.QUEST_SIMS_FACTORY (авторские сцены, механика = смысл)
```

Плюс ассеты тома: `img/` (картинки+постеры), `img/icons/` (свой лист иконок),
`audio/<lang>/` (озвучка карт). Эталон-инстанс — `decks/biblejskie-istorii/`.
Полный контракт полей — [`docs/product-quest.md`](../../../docs/product-quest.md).

## Что умеет движок из коробки

- **Заставка** тома (`#splash` + `#startbtn`) → **тропа эпох** с прогрессом,
  рангом и «Картой дня».
- **Задания**: авторские сцены тома (из `sims.js`) или простые задания движка
  (кто это / число / пара / чья вещь) для карт без своей сцены.
- **Награды**: звёзды (⭐/⭐⭐), медали эпох, супер-приз-грамота (печатается),
  фанфары (WebAudio, офлайн).
- **Альбом-коллекция**: добытые карты открываются (лицо-постер + изнанка-
  мини-энциклопедия с озвучкой), недобытые — плитки-загадки.
- **Карты мира**, **реконструктор** (пошаговые стройки), встраивание **книг**.
- **«Свободная игра»**: универсальные механики (пазл, найди на картине, слово,
  послушай, туман) на случайных картах.
- **Карта дня + мягкий стрик**, **ранги-звания** по проценту альбома.
- **Родительский режим**: замок-пример → прогресс по эпохам, награды, дневник
  успехов, вопрос для семейного разговора, настройки, сброс.

## localStorage

Все ключи с неймспейсом `VOLUME.ns` — тома **не пересекаются**:
`<ns>_prog`, `<ns>_lang`, `<ns>_snd`, `<ns>_parent`.

## Мультиязычность и офлайн

Все тексты — из `VOLUME.ui`/полей карт по `VOLUME.languages`; RTL движок
разворачивает сам. Шрифт и озвучка — локальные, работает без сети.
